# 싸중싸 그리기 대작전 — 실시간 멀티플레이

친구들에게 방 링크를 공유하면 회원가입 없이 닉네임과 캐릭터를 선택하고 플레이할 수 있습니다.

## 무료 서버 연결 (Render 예시)

1. https://github.com 에 무료 계정을 만들고 새 저장소(Repository)를 만듭니다.
2. 이 폴더 안의 `package.json`, `server.js`, `public` 폴더를 저장소에 올립니다. (폴더째가 아닌 **내용물**을 저장소 최상위에 올립니다.)
3. https://render.com 에 가입한 후 **New → Web Service → GitHub 저장소 연결**을 선택합니다.
4. Language/Runtime: **Node**, Build Command: `npm install`, Start Command: `npm start`로 설정합니다.
5. 무료 인스턴스(Free)가 제공된다면 선택하고 배포합니다. 무료 제공 여부 및 한도는 Render의 현재 정책에 따라 달라질 수 있습니다.
6. 배포된 `https://...onrender.com` 주소로 접속해 닉네임과 프사를 고르고 방을 만듭니다. 친구에게 **친구 초대 링크 복사** 버튼으로 링크를 공유합니다.

## 내 PC에서 실행

Node.js 20 이상 설치 후 이 폴더에서 `npm install` → `npm start` → http://localhost:3000 에 접속합니다.

## 규칙

- 2~12명, 60초 제한, 그림 그리는 사람은 순서대로 교대
- 출제자에게만 제시어가 전송되고, 정답자는 채팅으로 맞힙니다.
- 정답을 맞히거나 시간이 끝나면 정답 공개 4.5초 후 자동 다음 라운드
- 맞힌 사람에게 남은 시간에 따라 점수 부여

## 주의

- Render 무료 서비스는 유휴 시 잠들 수 있으며 처음 접속 시 잠시 기다려야 할 수 있습니다.
- 서버가 재시작되면 진행 중인 방과 점수는 사라집니다.
- 공개 인터넷 게임을 위한 운영급 보안, 신고/차단, 악성 사용자 대응은 추가 개발이 필요합니다.
- 제시어와 정답 판정은 서버에서 처리합니다. 브라우저에 다른 플레이어의 정답을 미리 보내지 않습니다.
